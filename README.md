# AI Face Recognition Smart Attendance Portal

An intelligent, full-stack automated attendance portal powered by deep learning face recognition. Built using **Python**, **Flask**, **OpenCV**, and **dlib's 128-dimensional ResNet Metric Model**.

---

## 🚀 Key Features

- 📸 **Live Webcam Face Recognition**: Continuous real-time face detection and identification with interactive bounding boxes and confidence scores.
- 🖼️ **Test Photo Upload Mode**: Drag-and-drop support for recognizing individual or group photos.
- ⚡ **Automated Attendance Logging**: Instantly marks recognised students as `Present` (or `Late` after cutoff time) while preventing duplicate marks on the same day.
- 📊 **Interactive Attendance Dashboard**: Search, filter by date and status, toggle attendance status, and export daily logs as CSV reports.
- 👥 **Student Directory**: Student roster with photos, roll numbers, and enrolment records.
- 🧠 **On-Demand Model Retraining**: Register new students with photo snapshots and instantly recompute facial embeddings.
- 📈 **Analytics & Diagnostics**: Real-time stats on attendance percentages, department distributions, and deep learning model encodings.

---

## 🛠️ Technology Stack

- **Backend**: Python 3.12, Flask 3.1
- **Computer Vision & Deep Learning**:
  - `face-recognition` & `dlib` (128-D Euclidean distance embedding space)
  - `OpenCV` (image preprocessing & frame scaling)
  - `Pillow` & `NumPy`
- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism Dark Theme, Outfit font), Vanilla JavaScript (Web Audio API synthesizer chimes, HTML5 Canvas bounding box overlay)

## ⚙️ Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/attendance-portal.git
   cd attendance-portal
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Train the Face Recognition Model:**
   ```bash
   python train_model.py
   ```

4. **Launch the Web Portal:**
   ```bash
   python app.py
   ```

5. **Open in Browser:**
   Navigate to `http://127.0.0.1:5000`

## 🌐 Mobile / Remote Access

To access the portal from your smartphone:
- **Public URL**: Access the secure HTTPS tunnel link generated by cloudflared.
- **Local Wi-Fi**: Open `http://<YOUR_PC_IP>:5000` from any device connected to the same Wi-Fi.

## 📋 API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Web portal UI |
| `GET` | `/api/stats` | Summary statistics & model health |
| `POST` | `/api/recognize` | Base64 frame face identification & attendance marking |
| `GET` | `/api/attendance` | Attendance records with date/status filter |
| `POST` | `/api/attendance/manual` | Manual override or entry |
| `GET` | `/api/export` | Download CSV attendance report |
| `GET` | `/api/students` | Get list of registered students |
| `POST` | `/api/students` | Register student with image and trigger retraining |
| `POST` | `/api/train` | Trigger full model retraining |
